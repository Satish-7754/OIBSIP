# OIBSIP Java - Online Reservation System

Oasis Infobyte Java Development Task 1.

## Tech Stack
- Java 17
- Swing GUI
- JDBC
- SQLite
- Maven

## Features
- Login validation
- Reservation form
- Train lookup by train number
- Automatic PNR generation
- Booking confirmation
- PNR-based booking lookup
- Ticket cancellation
- Input validation

## Run
1. Open this folder in IntelliJ IDEA.
2. Let Maven download dependencies.
3. Run `Main.java`.
4. Demo login:
   - Username: `admin`
   - Password: `admin123`

The SQLite database is created automatically as `reservation.db`.
